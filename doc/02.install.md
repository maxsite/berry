# Установка Berry CSS

Вы можете использовать уже готовый css-файл Berry CSS для своих проектов. Его можно разместить локально в произвольном месте вашего проекта, либо загрузить удалённо из CDN.

- [Zip-архив](https://github.com/maxsite/berry/archive/master.zip)
- [Berry CSS на GitHub.com](https://github.com/maxsite/berry)

Подключение Berry CSS:

```html
<!DOCTYPE HTML>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Sample page</title>
    <meta name="viewport" content="width=device-width, initial-scale=1, shrink-to-fit=no">
    <link rel="stylesheet" href="assets/css/berry.css">
...
```

Либо из CDN `https://cdn.jsdelivr.net/gh/maxsite/berry/css/berry.css`:

```html
<!DOCTYPE HTML>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Sample page</title>
    <meta name="viewport" content="width=device-width, initial-scale=1, shrink-to-fit=no">
    <link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/maxsite/berry/css/berry.css">
...
```

Если вам нужен форматированный css-файл, то он доступен по ссылке `https://cdn.jsdelivr.net/gh/maxsite/berry/css/berry-format.css`


## Использование Sass

При использовании SASS, достаточно скачать файлы Berry CSS и разместить их в каталоге своего проекта (например `sass`). Компиляция выполняется с помощью командной строки:

```
sass --watch sass:css --style=compressed --no-source-map

или

sass --update sass:css --style=compressed --no-source-map
```

Результат будет помещён в каталог `css`.

Рекомендуется использовать [Dart Sass](https://github.com/sass/dart-sass/releases) [описание](https://sass-lang.com/documentation/cli/dart-sass)
